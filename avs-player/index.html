Connection help

On the same network, paste http://RIG-IP:8080. The local player opens in its own tab because this page uses HTTPS.

For internet access, use the manager's HTTPS link. If the player shows no streamer, check the packaged game's Pixel Streaming plugin. If a streamer appears but video fails, check your TURN relay and firewall.

The rig must stay awake with the game running. This page cannot wake or start your PC.
